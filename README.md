# Active-Directory-Identity-and-Access-Management

1. Project Overview
This project demonstrates practical identity and access management and Windows Server administration. It simulates common IT support and IAM tasks performed when managing employee access to organizational resources.

2. Objectives
-Create and organize Active Directory users and Organizational Units
-Create and manage security groups
-Implement group-based access controls
-Configure NTFS permissions for department resources
-Apply least-privilege access principles
-Simulate employee onboarding
-Simulate employee offboarding
-Process a temporary access request
-Troubleshoot an access/authorization issue
-Document identity and access management procedures
